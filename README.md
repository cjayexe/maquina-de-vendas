Máquina de Vendas

Descrição

Projeto desenvolvido em Kotlin para simular uma máquina de vendas automática pelo terminal. O sistema permite visualizar produtos, consultar categorias, realizar compras, calcular o troco e controlar o estoque.

Funcionalidades

* Exibição de produtos e preços.
* Seleção de produtos pelo menu.
* Verificação de estoque disponível.
* Validação do valor inserido.
* Cálculo de troco.
* Atualização do estoque após cada compra.
* Possibilidade de realizar várias compras.

Como executar

1. Abra o projeto no IntelliJ IDEA.
2. Execute o arquivo `Main.kt`.
3. Escolha um produto digitando o número correspondente.
4. Informe o valor em reais e siga as instruções do terminal.
5. Digite `0` no menu principal para sair.

Tecnologias

* Kotlin
* IntelliJ IDEA
